Method

How the observatory works

Ask

Real coding questions go to free AI models, asked two ways.

Extract

Package names are parsed from install commands inside code only.

Verify

Each name is looked up on PyPI or npm: real, new, empty or missing.

Watch

Missing names are re-checked daily and stored encrypted.

Scan

Newly registered names are statically scanned in memory and reported.
