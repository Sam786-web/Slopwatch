AI supply-chain observatory

AI coding assistants invent packages. Attackers can register them.

When a model tells a developer to pip install a package that doesn't exist, anyone can publish malware under that name. This is called slopsquatting. SlopWatch asks AI models real coding questions, checks every recommended package against PyPI and npm, and watches the fake names every day.

Watchtower

Every fake name is re-checked daily. If someone registers one, it is downloaded and statically scanned for install hooks, obfuscated code and data exfiltration. Nothing is ever installed or run. Unregistered names are masked here so this page can't be used as a squatting list.

How it works

  1. AskRealistic coding questions (common, security and niche tasks) are sent to each model through free API tiers.
  2. ExtractPackage names are parsed from install commands and imports in code. Prose and placeholders are ignored.
  3. VerifyEvery name is looked up on PyPI and npm: established, brand-new, empty, or missing.
  4. WatchA daily GitHub Action re-checks missing names and flags any that get registered.
  5. ScanNewly registered packages are read in memory and scored with transparent rules plus Datadog GuardDog.

Limitations and responsible disclosure

  • Rates are measured on install commands only. Imports are tracked separately because import names often differ from package names.
  • Models marked low sample have fewer than 30 install recommendations so far, so their rates are not yet reliable.
  • "Missing" means missing at check time: a name may also belong to a package that was deleted earlier.
  • Unregistered fake names are kept encrypted in the repository and masked on this page. Malicious packages are reported to the registry before they are discussed publicly.
  • SlopWatch never registers hallucinated names itself.
